\# KickStartSoccer



KickStartSoccer is a youth-soccer practice-planning application.



\## MVP Goal



Help a coach browse drills and build a simple practice plan.



\## Technology



\- Frontend: Ionic Angular

\- Backend: Java 21 and Spring Boot

\- Source control: GitHub



\## Day 1 Milestone



\- \[ ] Ionic Angular app runs locally

\- \[ ] Spring Boot API runs locally

\- \[ ] Frontend displays the API health response
